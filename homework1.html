5. Discussion: one-way function vs hash function

Sensible properties for a one-way function (k ↦ kG)

  • Cost asymmetry. Forward costs O(log k) operations (double-and-add); backward is the ECDLP. This is not a statistical property: none of the tests above measure the difficulty of inversion, and failing a uniformity test does not break security.
  • Injectivity. For k in [1, n−1] every private key gives a different point (no collisions); for k ≥ n the trivial collisions k ≡ k mod n apply. The map does not compress, so "collision resistance" boils down to "key uniqueness".
  • Uniformity in the subgroup. If k is uniform, Q is uniform among the points generated by G (the map is bijective): a well-generated private key does not produce a skewed public key.
  • Intended algebraic structure. Qk1+k2 = Qk1 + Qk2 and x(Qk) = x(Qn−k). They are needed for signatures, ECDH and for recovering the public key from a signature; we verified them in the tests.

Typical hash function properties (not required of kG)

  • Avalanche effect / SAC (one input bit changes about half of the output) and independence of output bits: these are design goals of Keccak or SHA-2. For kG they are not needed and not guaranteed: k and k+1 give points related by +G.
  • Pseudorandom output on bit strings. Point coordinates have constraints: x < p (the high bits are unbalanced), only about half of the x values admit a point, y is determined by x up to sign (y² = x³ + 7). This is why the Ethereum address is a Keccak-256 hash of the public key and not the raw public key.
  • Collision, preimage and second-preimage resistance on arbitrary-length inputs and compression to a fixed length: these are requirements of a hash, not of a fixed-length one-way function like kG.
  • Absence of homomorphisms. A good hash has no algebraic relations between H(a), H(b) and H(a⊕b) or H(a+b). For kG, instead, they are present by construction.

Summary: statistics such as avalanche, correlations and bit uniformity speak to a hash; for kG what matters is the group structure, injectivity, uniformity in the subgroup and, above all, the hardness of the ECDLP, which cannot be measured this way.
