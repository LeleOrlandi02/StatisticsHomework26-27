1. Riemann vs. Lebesgue Integration: Slicing the Domain vs. Slicing the Range

The fundamental distinction between Riemann and Lebesgue integration lies in the orientation of decomposition:

Equation 1: Riemann Domain Partitioning
$$\int_a^b f(x) \, dx = \lim_{\|\mathcal{P}\| \to 0} \sum_{i=1}^n f(x_i^*) \Delta x_i, \quad x_i^* \in [x_{i-1}, x_i]$$

Bernhard Riemann (1854) partitions the domain $[a, b]$ into small subintervals of width $\Delta x_i$. In contrast, Henri Lebesgue (1902) famously observed: "Instead of adding money by collecting arbitrary coins in whatever order they come out of our pocket, we group all 1-cent coins together, all 5-cent coins together, and multiply each coin value by the measure of how many coins we have."

Equation 2: Lebesgue Range Partitioning
$$\int_{[a, b]} f \, d\lambda = \lim_{\|\mathcal{Q}\| \to 0} \sum_{j=1}^m y_j^* \cdot \lambda\left( E_j \right), \quad E_j = f^{-1}([y_{j-1}, y_j)) = \{ x \in [a, b] : y_{j-1} \le f(x) < y_j \}$$

where $\lambda(E_j)$ represents the Lebesgue measure (generalized length) of the preimage set $E_j$.

2. The Vitali-Lebesgue Criterion for Riemann Integrability

When do the Riemann and Lebesgue integrals coincide? The celebrated Lebesgue-Vitali Theorem provides the exact necessary and sufficient condition:

Theorem: Lebesgue's Integrability Criterion
$$\text{A bounded function } f: [a, b] \to \mathbb{R} \text{ is Riemann integrable if and only if its set of discontinuities } \mathcal{D}_f \text{ has Lebesgue measure zero: } \lambda(\mathcal{D}_f) = 0.$$

Analysis of the Test Suite:

  • Continuous Functions ($\sin x$, $x^2$, $|x-0.5|$, $\text{sinc } x$): Here $\mathcal{D}_f = \emptyset$ (or a single point), so $\lambda(\mathcal{D}_f) = 0$. Both approaches converge unconditionally to identical values.
  • Step Function ($f(x) = 1$ if $x < 0.5$ else $3$): Has a single jump discontinuity at $x=0.5$. Since a singleton has measure zero ($\lambda(\{0.5\}) = 0$), the function is Riemann integrable with integral $2.0$.
  • Dirichlet Function ($1$ on $\mathbb{Q}$, $0$ on $\mathbb{R}\setminus\mathbb{Q}$): Discontinuous at every point in $[0, 1]$, so $\mathcal{D}_f = [0, 1]$ and $\lambda(\mathcal{D}_f) = 1 \ne 0$. For any partition $\mathcal{P}$, the infimum is $0$ and supremum is $1$, so lower Darboux sum $L=0$ and upper Darboux sum $U=1$. Riemann integral does not exist. In Lebesgue theory, $\mathbb{Q} \cap [0, 1]$ is countable, so $\lambda(\mathbb{Q})=0$, and $f = 0$ almost everywhere (a.e.). Thus $\int f d\lambda = 0 \cdot 1 + 1 \cdot 0 = 0$.
  • Thomae's Function: Continuous at all irrational points and discontinuous at all rational points. Since $\mathcal{D}_f = \mathbb{Q} \cap [0, 1]$ is countable, $\lambda(\mathcal{D}_f) = 0$. Therefore, Thomae's function is Riemann integrable, and both integrals equal $0$.
  • Singular Function $1/\sqrt{x}$: Unbounded as $x \to 0^+$, so it fails the strict definition of Riemann integrability on $[0, 1]$ and requires an improper limit $\lim_{\epsilon \to 0^+} \int_\epsilon^1 x^{-1/2} dx = 2.0$. In Lebesgue theory, non-negative measurable functions do not require separate improper limits; the monotone convergence theorem integrates unbounded measurable functions directly.

3. Liouville's Theorem: Why the Normal CDF Cannot Be Expressed in Elementary Terms

The standard normal probability density function is given by $\phi(t) = \frac{1}{\sqrt{2\pi}} e^{-t^2/2}$. Why has no mathematician ever found a closed-form formula for $\int e^{-t^2/2} dt$ using polynomials, sines, cosines, logarithms, or exponentials?

The answer was established by Joseph Liouville in 1835 in differential algebra.

Theorem: Liouville's Integration in Finite Terms (1835)
$$\text{Let } f(x) \text{ and } g(x) \text{ be rational functions with } g(x) \text{ non-constant. The antiderivative } \int f(x) e^{g(x)} \, dx \text{ is elementary if and only if}$$ $$\text{there exists a rational function } R(x) \in \mathbb{C}(x) \text{ satisfying the differential equation: } R'(x) + R(x) g'(x) = f(x).$$

Applying Liouville’s theorem to the Gaussian integrand $\int e^{-x^2/2} dx$, we set $f(x) = 1$ and $g(x) = -x^2/2$, so $g'(x) = -x$. The Liouville differential equation becomes:

The Gaussian Differential Equation
$$R'(x) - x R(x) = 1$$

Proof of Impossibility: Suppose for contradiction that there exists a rational function $R(x) = \frac{P(x)}{Q(x)}$ satisfying this equation, where $P(x)$ and $Q(x)$ are co-prime polynomials ($\gcd(P, Q) = 1$):

$$\frac{P'(x)Q(x) - P(x)Q'(x)}{Q(x)^2} - x \frac{P(x)}{Q(x)} = 1 \implies P'(x)Q(x) - P(x)Q'(x) - x P(x)Q(x) = Q(x)^2$$

If $\deg(Q) \ge 1$, let $x_0$ be a root of $Q(x)$ with multiplicity $m \ge 1$. The term $P(x)Q'(x)$ has a root of multiplicity $m-1$, while $Q(x)^2$ has multiplicity $2m$ and $P'(x)Q(x)$ has multiplicity $\ge m$. This creates an irreducible pole on the left-hand side, forcing $Q(x)$ to be a constant polynomial!

If $Q(x)$ is constant, then $R(x)$ must be a polynomial $P(x)$. Let $\deg(P) = d \ge 0$:

$$\deg(P'(x) - x P(x)) = \deg(-x P(x)) = d + 1$$

However, the right-hand side is $1$, which has degree $0$. Thus $d + 1 = 0 \implies d = -1$, meaning no such polynomial exists!

This concludes the proof: no elementary antiderivative exists for $e^{-x^2/2}$. Consequently, numerical methods and special functions are an absolute mathematical necessity.

4. Special Functions ($\text{erf}$) & Numerical Methodologies

To work with this non-elementary integral, mathematicians defined the Error Function $\text{erf}(x) = \frac{2}{\sqrt{\pi}} \int_0^x e^{-u^2} du$, giving the exact identity:

Equation 3: Normal CDF via Error Function
$$\Phi(z) = \frac{1}{2} \left[ 1 + \text{erf}\left(\frac{z}{\sqrt{2}}\right) \right] = 1 - \frac{1}{2} \text{erfc}\left(\frac{z}{\sqrt{2}}\right)$$

Why Numerical Approximations Are Still Required: The error function is non-elementary. On digital microprocessors, evaluating $\text{erf}(x)$ requires numerical evaluation. We investigated four core paradigms:

  • 1. Numerical Quadrature (Composite Simpson's Rule): Divides $[0, z]$ into $N$ intervals. While robust, it requires $O(N)$ floating-point evaluations per query, rendering it prohibitively slow for high-throughput Monte Carlo or statistical libraries.
  • 2. Taylor Power Series: Expanding $e^{-u^2}$ yields $\text{erf}(x) = \frac{2}{\sqrt{\pi}}\sum_{k=0}^\infty \frac{(-1)^k x^{2k+1}}{k!(2k+1)}$. For $|z| \le 1.5$, this converges in fewer than 15 terms. However, for $|z| > 2.5$, the alternating terms grow to huge magnitudes before shrinking, causing severe catastrophic floating-point cancellation that completely destroys precision!
  • 3. Abramowitz & Stegun Rational Approximation (Formula 7.1.26): Employs a degree-5 rational polynomial in $t = \frac{1}{1 + px}$. It runs in $O(1)$ constant time with an error bounded by $1.5 \times 10^{-7}$. It is suitable for 32-bit floats and graphics shaders, but inadequate for scientific double-precision calculations ($10^{-16}$).
  • 4. Cody’s Rational Chebyshev Minimax Approximation (Chosen Method): Segmented into 3 optimized rational domains ($|x| \le 0.46875$, $0.46875 < |x| \le 4.0$, and $|x| > 4.0$). It guarantees uniform machine precision ($|\epsilon| < 2.22 \times 10^{-16}$) across $(-\infty, +\infty)$ in $O(1)$ constant time, and operates on $\text{erfc}$ to eliminate catastrophic subtraction in the extreme tails.
