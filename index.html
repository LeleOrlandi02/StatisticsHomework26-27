Toy ECC: Private Key to Public Key

secp256k1 Toy Curve • Modular Arithmetic • OWF Analysis

Interactive laboratory exploring the toy elliptic curve y² = x³ + 7 (mod p) modeled after Ethereum's secp256k1. Computes scalar multiplication Q = kG using repeated addition and fast double-and-add algorithms.

  • Interactive slow-motion chord-and-tangent canvas animation
  • Empirical statistical tests for uniformity, correlation & symmetry
  • Rigorous discussion: One-Way Functions vs. Cryptographic Hash Functions

From Wallet Seed to Ethereum Address

BIP-39 • BIP-32/44 • secp256k1 • Keccak-256 • EIP-55

End-to-end practical cryptographic pipeline used in Ethereum wallets: from mnemonic sentence to binary seed, hierarchical deterministic key derivation, elliptic-curve public keys, Keccak-256 hashing, and EIP-55 mixed-case checksum encoding.

  • Interactive live pipeline generator: Mnemonic → 512-bit Seed → Private Key → PubKey → Address
  • Rigorous taxonomy: Key Generation vs. Derivation, Public-Key Crypto, Hashing, Checksums & Encoding
  • Empirical statistical lab: Strict Avalanche Criterion (SAC), 256-bit flip matrix & collision probabilities
  • Historical chronology (RSA 1977 → EIP-55 2016) & Keccak-256 vs. NIST SHA3-256 padding duel
  • Software wallet analysis: Key lifecycle and derivation in MetaMask, Rabby, Exodus & Rainbow
